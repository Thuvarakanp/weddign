NIROSAN & SAJITHA | ENGAGEMENT WEBSITE

GET STARTED
Extract this ZIP and open index.html in your browser.
For a local web preview, run: python -m http.server 8000
Then open http://localhost:8000

EDIT EVENT DETAILS
Edit event-config.js for the names, event time, contact, venue and image paths.
Update matching fallback text in index.html if changing event details.

DESIGN
styles.css contains the base layout.
celebration.css contains the charcoal-and-gold design and animations.
app.js contains the countdown, calendar download and RSVP preparation.
celebration.js contains the opening, motion controls and photo gallery.
assets/ contains your portraits and logo.

RSVP
The form prepares a text message. Guests must send it from their messaging app.
Nothing is sent automatically, and responses are not stored on the website.
The calendar uses the 6:30 PM Toronto start time with no end time assumed.

HOSTING
Upload all files and the assets folder together to any static website host.
Google fonts and the venue map need an internet connection.
The clipboard option works best on HTTPS or localhost.

CHECKS
JavaScript syntax, local asset paths, navigation links, field labels and the
Toronto event timestamp were checked. Browser and mobile visual testing
remain unverified.
